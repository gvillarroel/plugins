# Procedencia de la adaptación

Esta implementación nueva emplea una receta JSON, Pillow y FFmpeg. Toma como referencia tres decisiones de Huashu Motion 0.6.0: conservar la posición de un sujeto entre planos, preparar una secuencia de datos antes de señalar su conclusión, y reservar pausas de lectura con duraciones diferentes. La guía de dirección y la receta de ejemplo se escribieron para Line World. El original ofrece una CLI Node 22+, un reproductor, proyectos HTML y un motor por tiempo. La plantilla financiera encadena estructura, datos y anotación final. La plantilla de tipografía cinética organiza el relato alrededor de palabras seleccionadas, y la plantilla de UI centra cada plano en una operación. La demostración del té combina una línea temporal de GSAP con recursos gráficos y fuentes propios. Line World realiza su propia traducción por medio de rastro, punto de lectura y barras a escala compartida. Los valores del ejemplo son simulados.
