# Line World images

Determine what the image must establish on screen. A generated illustration
can introduce an unfamiliar object or depict a metaphor. Use an attributable
photograph for an actual person, place, event or model. Draw scales, numbers,
labels and changing relationships from the source data in the video renderer.

Frame the prompt for the asset's actual shot. State which details must fit the
crop, where a caption will sit and which element gets attention while it is
spoken. Keep artwork and overlaid text on separate layers.

Use the [Codex image direction guide](../line-world-video/references/codex-images.md)
for the built-in generate and edit operations. Store the approved bitmap in
the project and record its prompt, use and hash with the [image asset helper](../line-world-video/scripts/codex_image_asset.py).
Check the final scene at native and mobile width. Preserve the accepted
bitmap when rebuilding a film so the frames reproduce.

For a transparent cutout, check the alpha channel and view its silhouette
and internal openings on white and on the intended contrasting background.
For a nominally solid object, record the fraction of visible pixels near
full opacity. Keep exact quantities, labels and scale marks in a separate
code layer. Use decoded video samples to confirm that the bitmap and the
numerical graphic both read at delivery size.
